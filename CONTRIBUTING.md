# Contributing

Contributions are welcome through GitHub pull requests.

- Keep changes focused and describe the behavior or documentation change.
- Add or update tests for code changes and run the relevant test project(s).
- Update directly related documentation.
- Do not include credentials, private hosted-script URLs, personal data, or other secrets in commits or reports.
- By submitting a contribution, you confirm you have the right to submit it and agree that your contribution is provided under the repository's MIT License. Each contributor retains copyright in their own contributions. No separate contributor license agreement (CLA) is required.
