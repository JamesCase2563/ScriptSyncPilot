# Security policy

## Reporting a vulnerability

Do not post vulnerability details, proof-of-concept code, personal data, Handy connection keys, or generated/private script URLs in a public issue.

GitHub private vulnerability reporting is enabled for this public repository. Use **Security and quality → Advisories → Report a vulnerability** to submit a report privately. Do not send vulnerability details through a public issue.

## Support

Use [GitHub Issues](https://github.com/JamesCase2563/ScriptSyncPilot/issues) for ordinary support. Issues are publicly accessible. Do not include personal data, connection keys, private script URLs, private media, or unreviewed settings/log files. Support is best-effort with no response-time or fix guarantee.
