# Security policy

## Reporting a vulnerability

Do not post vulnerability details, proof-of-concept code, personal data, Handy connection keys, or generated/private script URLs in a public issue.

This repository is currently private and no external private reporting channel has been published. GitHub private vulnerability reporting can be enabled by the repository owner after the repository is public. When enabled, use **Security and quality → Advisories → Report a vulnerability**. Do not send vulnerability details through a public issue. Until the private reporting form is available and verified, external users have no security-reporting route and a public release is blocked.

## Support

Use [GitHub Issues](https://github.com/JamesCase2563/ScriptSyncPilot/issues) for ordinary support. The repository is currently private, so only people with repository access can use this route. Do not include personal data, connection keys, private script URLs, private media, or unreviewed settings/log files. Support is best-effort with no response-time or fix guarantee.
