# Security policy

## Reporting a vulnerability

Do not post vulnerability details, proof-of-concept code, personal data, Handy connection keys, or generated/private script URLs in a public issue.

This repository is private and no private reporting channel has been published. GitHub's private vulnerability reporting feature is limited to public repositories, so it cannot currently be used here. Do not send sensitive details through an issue. External users currently have no security-reporting route; public releases are blocked on establishing and verifying one.

## Support

People with repository access can use [GitHub Issues](https://github.com/Frank-Yong/ScriptSyncPilot/issues) for ordinary support. Do not include personal data, connection keys, private script URLs, private media, or unreviewed settings/log files. Support is best-effort with no response-time or fix guarantee.
