# Buttplug Protocol — Local Reference Notes

This file points to the official Buttplug protocol documentation and gives instructions to obtain a local copy.

Official documentation
- Protocol spec (web): https://buttplug.io/docs/spec
- Project repo: https://github.com/buttplugio/buttplug
- Docs repo (documentation source): https://github.com/buttplugio/docs.buttplug.io

How to get a local copy
1. Clone the docs repo (preferred for spec markdown):

```bash
git clone https://github.com/buttplugio/docs.buttplug.io.git
```

2. Or clone the main project (contains protocol implementation and core message schema):

```bash
git clone https://github.com/buttplugio/buttplug.git
```
