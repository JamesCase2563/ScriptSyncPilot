# Handy Movement Protocols

## Overview
Handy Movement Protocols define how the Handy device interprets and executes different types of movements. Each protocol is designed for specific hardware capabilities and use cases, allowing the device to handle a variety of content and interaction scenarios.

## Protocol Types

### HVP - Handy Vibration Protocol
- **Purpose:** Standard protocol for the Oh! device.
- **Functionality:** Controls the device's hardware to manage vibration frequency and patterns.
- **Use Case:** Used when vibration-based feedback is required.

### HAMP - Handy Alternating Movement Protocol
- **Purpose:** Standard protocol for the Handy device.
- **Functionality:** Controls the motor and speed, calculating optimal speed to synchronize with content.
- **Use Case:** Used for movement-based synchronization with scripts and interactive content.

### HRPP - Handy Repeating Pattern Protocol
- **Purpose:** Stores and reproduces scripts locally on the device.
- **Functionality:** Enables playback of stored scripts, such as triggering script playback via a button press.
- **Use Case:** Useful for offline or quick-access script playback scenarios.

## Why Multiple Protocols?
Different content types and hardware features require tailored protocols to ensure optimal performance and compatibility. Protocols may evolve or be added as new features and devices are introduced.
