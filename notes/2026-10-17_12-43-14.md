I wrote the process in `scripting-workflow.md`. Your approach works with the editor, but I simplified it in three ways.

**1. Six levels reduced to three.** The script only needs to know whether the device moves and how fast:
- **Cut** (optional): replaces Scene and Take. Useful only as landmarks in long or busy videos.
- **Movement section**: replaces Action, Session and Movement. A new action only matters if the movement or tempo changes, and then it becomes a new section or a tempo change anyway.
- **Tempo**: unchanged from your plan.

**2. Each marker type gets its own value instead of alternating min and max.** Markers are ordinary script points, so the device moves to them. Distinct values keep the levels easy to tell apart and never collide with tempo taps.

| Marker | Key | Position |
| --- | --- | --- |
| Scene change | `9` | 90% |
| Cut | `5` | 50% |
| Movement start | `7` | 70% |
| Movement stop | `3` | 30% |
| Tempo tap | key left of `1` | 0% |

**3. Tap once per full stroke, always at the bottom.** For a run of evenly spaced taps, the pattern's cycle count is then simply the number of taps minus one.

The passes:
1. **Cuts** (optional, 2x).
2. **Movement start/stop** (1.5–2x).
3. **Tempo taps** inside movement sections only (0.5–1x; slowing playback doesn't distort the timing).
4. **One pattern with Replace per constant-tempo run**, using the first and last tap as start and end times.
5. **Cleanup and review** with the device at 1x.

Three things the editor does that the process has to work around:
- **Replace keeps the points at the range boundaries.** The first and last tap stay as bottom points, which also joins consecutive tempo runs cleanly. If the stroke minimum isn't 0%, those two points dip slightly below the pattern; drag them up or accept the dip.
- **Leftover markers still move the device.** In pass 5, drag the 70%/30% markers to the rest position and delete or flatten the cut markers.
- **Pattern insertion deletes the tap markers.** The document suggests saving a copy before pass 4 to keep the hand-marked structure.

The planned Markers and Chapters features in the backlog would let structure markers live outside the movement script, which would remove most of the cleanup pass.
