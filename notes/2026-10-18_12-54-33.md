**Yes—partly.** Handy’s official docs establish the hosting and device-sync behavior, but they don’t disclose every data-retention detail.

- The [Hosting API spec](https://www.handyfeeling.com/api/hosting/v2/docs/spec.yaml) says script uploads use a file field and return a **temporary download URL**. It supports CSV uploads, but doesn’t specify how long the uploaded file remains available.
- The [Handy privacy policy](https://www.thehandy.com/privacy-policy/) says that for online third-party synchronization, Handy processes the connection key and IP address, device state, third-party provider identification, and script download URL. It says session data is deleted within an hour after logoff and that the device retains the script until it is overwritten. **It doesn’t clearly say that the one-hour deletion period applies to the separately uploaded CSV.**
- The app’s implementation shows the precise requests: it uploads a CSV containing the funscript action timestamps and positions, receives a URL, and passes that URL plus playback timing to HSSP. The REST requests also include connection-key and application-identifier headers. See `HandyApiClient.cs` and `Funscript.cs`.
